# musical files

store files as "music"

## Usage

Encode:
```sh
./encode
```
```pwsh
.\encode.exe
```

Decode:
```sh
./decode
```
```pwsh
.\decode.exe
```

## Building

Compile `decode.cpp` and `encode.cpp` with your desired C++ compiler.
```sh
# Example
g++ decode.cpp -o decode
g++ encode.cpp -o encode
```
